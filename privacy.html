プライバシーポリシー

対象：GitHub ユーザー yujita が個人で使う OAuth クライアント（Google Workspace CLI 用）。最終更新日：2026年10月4日

  1. 利用者　このクライアントを使うのは開発者本人だけです。一般向けのサービスではありません。
  2. 取得するデータ　本人が同意した範囲（例：Gmail のメールの閲覧・送信・ラベル操作）で、本人の Google アカウントのデータにアクセスします。
  3. 利用目的　本人の端末から、本人のメールの確認・送信・整理を自動化するためだけに使います。
  4. 保存　データと認証情報は本人の端末内にだけ保存します（認証情報は暗号化）。開発者のサーバーへは送りません。
  5. 第三者への提供　データを第三者に提供・販売せず、広告にも使いません。Google API から受け取ったデータの利用と移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。
  6. アクセスの取り消し　Google アカウントの「サードパーティのアプリとサービス」から、いつでもアクセスを取り消せます。
  7. 問い合わせ　GitHub の Issues へどうぞ。

Privacy Policy (English)

  1. Users: This OAuth client is used only by its developer (GitHub user yujita). It is not offered to the public.
  2. Data accessed: Only the developer's own Google account data within the scopes the developer has granted (e.g. reading, sending and labeling Gmail messages).
  3. Purpose: Solely to let the developer check, send and organize their own email from their own computers.
  4. Storage: Data and credentials are stored only on the developer's own devices (credentials are encrypted). Nothing is sent to any server operated by the developer.
  5. Sharing: Data is never sold, shared with third parties, or used for advertising. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  6. Revoking access: Access can be revoked at any time at Google Account > Third-party apps & services.
  7. Contact: GitHub Issues.
