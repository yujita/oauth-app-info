個人用 Google Workspace CLI（OAuth クライアント）

  • データの取り扱いは プライバシーポリシー をご覧ください。

Personal Google Workspace CLI (OAuth client)

This page describes an OAuth client used privately by the GitHub user yujita. It lets the developer access their own Google account (e.g. Gmail) from a command-line tool (Google Workspace CLI) on their own computers. It is not a public service and has no users other than the developer. See the Privacy Policy.
